# Artwork provenance

Built-in OpenAI imagegen produced the transparent raster artwork. Generation
prompts for Grove, the original amber assistant icon, Explorer and the CF mark
are in `prompts/`. The single-C and nested-CF Cashflo directions were rejected;
the nested version read as E. The next chunky chrome letters were rejected
while their blue/green/purple palette was accepted. The replacement uses separated C/F silhouettes,
baby-blue faces, light-green chrome and lilac reflections at the owner's request.
The tapered ribbon CF was also rejected as too wispy/ornamental. The replacement
compact angular CF has strong beveled faces, mint chrome edges and purple inner
facets. The owner approved this fourth CF pass. Only that approved replacement
is active in the dock/package. The Explorer icon is an original teal
and gold folder, not a Microsoft logo.
The default companion is an original woodland adventurer, with no account-based
identity or character clone. Its nine-pose atlas is used only as local artwork.
Visual inspection found the upward diagonal poses exchanged in the generated
sheet; the runtime maps logical directions to source cells `[2,1,0,3,4,5,6,7,8]`.
The PNG is preserved unmodified. Frames are sliced and scaled during rendering.

The Hugin raven, Parley mint waves, Promtly purple ribbon and AEVUM glass worldseed
are the owner's approved platform marks from the October 4 artwork pass, reused
with the owner's express request for this public dock. They identify the default
platform links. Source images have genuine alpha; no backgrounds are removed by
an ad hoc processing script. The silverpath and MixForge marks and personal
avatar are deliberately absent from this public configuration.

MIT covers the source code. The bundled generated companion/assistant artwork
may be reused and modified with this package. Platform marks remain their
respective brands; this package grants their use as default link icons, without
claiming exclusive ownership of AI-generated material or granting a brand name.
